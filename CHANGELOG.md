# Changelog

## 1.5.0 — 2026-11-03

First public release of Firewall Map+ for Omarchy.

- Native live OPNsense traffic map, cached hostnames and per-IP row actions.
- Full-world fit with drag-to-pan, pointer-centered wheel zoom and Fit controls.
- Clickable Flows, Blocked and Threats counts with live host lists.
- Map background clicks return to Flows; points and connections select hosts.
- A readable line-color legend directly below the map.
- One block control per row, without duplicate actions or host popups.
- Repaint recovery after reopening and independent traffic/action sessions.
- Atomic private credential storage, setup guide and synthetic preview images.
